IT Troubleshooting Guides

Common technical issues, possible causes and systematic troubleshooting procedures.

01 Windows OS

Computer Running Slow

Problem: Windows system takes too long to start or respond.

Possible Causes: High CPU/RAM usage, insufficient storage, startup applications or malware.

Troubleshooting Steps

  1. Open Task Manager using Ctrl + Shift + Esc.
  2. Check CPU, Memory and Disk utilization.
  3. Disable unnecessary startup applications.
  4. Check available disk space.
  5. Run Windows Defender scan.
  6. Restart and verify system performance.
Useful Command cleanmgr
02 Networking

No Internet Connectivity

Problem: User cannot access the internet.

Possible Causes: Incorrect IP configuration, DNS issues, disconnected cable or router problems.

Troubleshooting Steps

  1. Check Wi-Fi or Ethernet connectivity.
  2. Verify IP configuration.
  3. Ping the default gateway.
  4. Test connectivity using an external IP.
  5. Check DNS resolution.
  6. Escalate if the network infrastructure is down.
Useful Commands ipconfig /all ping 8.8.8.8 nslookup google.com
03 Hardware

Computer Not Powering On

Problem: Desktop computer does not start when the power button is pressed.

Possible Causes: Power cable issue, faulty power supply, loose connections or hardware failure.

Troubleshooting Steps

  1. Check the power socket and power cable.
  2. Verify the SMPS power switch.
  3. Check power indicators and fan activity.
  4. Inspect external connections.
  5. Perform further hardware diagnosis if trained.
  6. Escalate suspected component failure.
Diagnostic Area Hardware Inspection
04 Printer Support

Printer Not Printing

Problem: Print jobs are stuck or the printer does not respond.

Possible Causes: Printer offline, driver issues, connection problems or stuck print queue.

Troubleshooting Steps

  1. Check printer power and connectivity.
  2. Verify printer status in Windows Settings.
  3. Check the default printer selection.
  4. Clear stuck jobs from the print queue.
  5. Restart the Print Spooler service.
  6. Update or reinstall the correct driver.
Useful Command services.msc
05 Microsoft Outlook

Outlook Not Opening

Problem: Microsoft Outlook fails to start or becomes unresponsive.

Possible Causes: Faulty add-ins, corrupted Outlook profile, application issues or damaged data files.

Troubleshooting Steps

  1. Close Outlook completely.
  2. Open Run using Windows + R.
  3. Run Outlook in Safe Mode.
  4. Disable problematic add-ins if identified.
  5. Check account and profile configuration.
  6. Repair Microsoft 365 if required.
Useful Command outlook.exe /safe
06 Software & Drivers

Device Driver Not Working

Problem: Hardware device is not functioning correctly in Windows.

Possible Causes: Outdated, missing, incompatible or corrupted device drivers.

Troubleshooting Steps

  1. Open Device Manager.
  2. Identify devices showing warning icons.
  3. Check the device status and error code.
  4. Download the correct driver from the manufacturer.
  5. Install or update the driver.
  6. Restart and verify device functionality.
Useful Command devmgmt.msc
