TECHNICAL REFERENCE LIBRARY

Knowledge Base

A collection of technical commands, networking concepts and IT support reference notes.

01

Windows CMD Commands

Command Purpose
sfc /scannow Scans and repairs protected Windows system files.
chkdsk Checks a volume for file-system errors.
ipconfig /all Displays detailed IP configuration.
ipconfig /flushdns Clears the DNS resolver cache.
systeminfo Displays system configuration information.
tasklist Displays running processes.
taskkill Terminates a running process.
DISM /Online /Cleanup-Image /RestoreHealth Repairs the Windows component store.
02

Windows Run Commands

Run Command Purpose
devmgmt.msc Opens Device Manager.
diskmgmt.msc Opens Disk Management.
services.msc Opens Windows Services.
eventvwr.msc Opens Event Viewer.
ncpa.cpl Opens Network Connections.
appwiz.cpl Opens Programs and Features.
msconfig Opens System Configuration.
control Opens Control Panel.
03

Networking Commands

Command Purpose
ping 8.8.8.8 Tests IP connectivity using ICMP Echo.
tracert google.com Displays the route packets take to a destination.
nslookup google.com Queries DNS records.
arp -a Displays the ARP cache.
route print Displays the IP routing table.
netstat -ano Displays network connections and process IDs.
04

Linux Commands

Command Purpose
pwd Displays the current working directory.
ls -la Lists files, including hidden files.
cd Changes the current directory.
mkdir Creates a directory.
chmod Changes file or directory permissions.
chown Changes file or directory ownership.
systemctl status Checks the status of a systemd service.
ip addr Displays network interface addresses.
df -h Displays disk space usage.
free -h Displays memory usage.
05

Networking Protocols & Ports

Protocol Port Purpose
HTTP TCP 80 Web communication.
HTTPS TCP 443 Secure web communication.
FTP TCP 20, 21 File transfer (active mode data and control).
SSH TCP 22 Secure remote access.
Telnet TCP 23 Unencrypted remote terminal access.
SMTP TCP 25 Email transfer between mail servers.
DNS TCP/UDP 53 Domain name resolution.
DHCP UDP 67, 68 Automatic IP address configuration.
POP3 TCP 110 Email retrieval.
IMAP TCP 143 Email access and synchronization.
RDP TCP/UDP 3389 Remote Desktop access.
SNMP UDP 161, 162 Network monitoring and notifications.
LDAP TCP/UDP 389 Directory service access.
LDAPS TCP 636 LDAP over TLS.

Note: These are common default ports. Actual port usage may vary depending on configuration and service.

06

IT Support Fundamentals

Incident Management

Restoring normal IT service operation as quickly as possible after an incident.

Service Request

A formal request from a user for a standard IT service or information.

Root Cause Analysis

Identifying the underlying reason behind a recurring or major issue.

SLA

Service Level Agreement defines agreed service targets and expectations.

Escalation

Transferring an unresolved issue to the appropriate support team.

Ticket Management

Recording, tracking, updating and resolving user-reported IT issues.
